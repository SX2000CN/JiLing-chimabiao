### Bug #1: Ctrl+S 大写锁定兼容 ✅
- **问题**: 开启大写锁定后 Ctrl+S 快捷键失效
- **修复**: 支持 `Ctrl+s` 和 `Ctrl+S` 两种情况
- **位置**: `App.jsx` 第130行

### Bug #2: Tab键焦点循环优化 ✅
- **问题**: Tab键从起始值输入框跳出到整个页面元素
- **修复**: 实现起始值输入框内的智能循环
- **功能**: 支持 Tab 正向循环、Shift+Tab 反向循环
- **位置**: `SizeSettings.jsx` 新增键盘事件处理
