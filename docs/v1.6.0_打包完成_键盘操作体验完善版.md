## 🧪 重点测试场景

### 1. 大小写锁定测试 ⭐ 重要
**测试步骤：**
1. 开启键盘大写锁定 (Caps Lock)
2. 选择尺码类别
3. 按 `Ctrl+S` → 应该正常导出并显示成功提示

**预期结果：**
- 底栏显示绿色"💾 图片导出成功"或"📁 图片已保存到指定路径"
- 图片成功导出，格式正确

### 2. Tab键循环测试 ⭐ 重要
**测试步骤：**
1. 选择3-4个尺码类别（如胸围、袖长、肩宽、下摆围）
2. 点击第一个起始值输入框
3. 连续按 `Tab` 键观察焦点移动

**预期结果：**
- 焦点在起始值输入框间循环：胸围 → 袖长 → 肩宽 → 下摆围 → 胸围 (循环)
- 不会跳转到关闭按钮或其他页面元素
- 在最后一个输入框按 Tab 直接回到第一个

### 3. 反向循环测试
**测试步骤：**
1. 在任意起始值输入框按 `Shift+Tab`
2. 观察焦点移动方向

**预期结果：**
- 焦点反向移动：当前 → 上一个输入框
- 第一个输入框按 `Shift+Tab` 跳到最后一个

### 4. 综合工作流测试
**完整操作流程：**
1. 选择多个类别
2. 使用 Tab 键在输入框间导航
3. 设置各类别的起始值
4. 使用 Ctrl+S 导出（测试不同键盘状态）
5. 验证导出的表格格式
