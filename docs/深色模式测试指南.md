# 深色模式测试指南

## 功能测试清单

### 1. 主题切换基本功能
- [ ] 打开应用，确认默认为浅色主题
- [ ] 点击右上角"设置"按钮
- [ ] 切换到"通用设置"标签页
- [ ] 找到"主题设置"区域
- [ ] 确认显示"当前主题：浅色模式"
- [ ] 点击"切换到深色"按钮
- [ ] 验证界面立即切换到深色主题
- [ ] 确认按钮文字变为"切换到浅色"
- [ ] 确认状态显示"当前主题：深色模式"

### 2. 设置持久化测试
- [ ] 在深色模式下关闭设置面板
- [ ] 刷新页面（F5）
- [ ] 确认应用保持深色主题
- [ ] 重新打开设置面板
- [ ] 确认显示"当前主题：深色模式"

### 3. 主题色彩验证
**深色模式特征：**
- [ ] 背景色：深灰色调 (#1C1C1E 系列)
- [ ] 文本色：浅色 (#F2F2F7 系列)
- [ ] 边框色：中等灰色 (#3A3A3C 系列)
- [ ] 系统色彩：适配深色环境的亮度

**浅色模式特征：**
- [ ] 背景色：白色/浅灰 (#FFFFFF, #F8F9FA)
- [ ] 文本色：深灰/黑色 (#111827 系列)
- [ ] 边框色：浅灰 (#E5E7EB 系列)

### 4. 界面元素检查
- [ ] 工具栏在两种主题下显示正常
- [ ] 侧边栏类别列表颜色适配正确
- [ ] 主内容区域背景色正确
- [ ] 状态栏文字颜色可读性良好
- [ ] 设置面板各个控件主题一致

### 5. 交互体验测试
- [ ] 主题切换过程流畅，无闪烁
- [ ] 切换后所有UI元素立即更新
- [ ] 按钮悬停状态在两种主题下都正常
- [ ] 输入框在深色模式下输入清晰可见

## 已知限制
- 当前版本不支持跟随系统主题自动切换
- 主题切换暂无动画过渡效果
- 仅支持两种预设主题（浅色/深色）

如发现以下问题请记录：
- [ ] 主题切换失败或不完整
- [ ] 某些UI元素颜色异常

- [ ] 性能影响
